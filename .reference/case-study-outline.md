# Case Study Outline

Use this structure for every project markdown file in `projects/`.

## Frontmatter (metadata)

- title: (short project name, e.g. "Phishing Simulation Platform")
- framing_line: (one-sentence thesis/reframe — used as hero subhead)
- company:
- role:
- timeline:
- team:
- thumbnail:
- pills: (tags shown on the Works page card, e.g. ["Enterprise", "0-to-1"])

## Body sections

### Project Summary (STAR format)

- **Problem** — what was broken/needed, context and constraints
- **Action** — your approach, key decisions, systematic thinking made visible
- **Result** — what shipped, impact/results, ideally quantified

### Slides *(optional)*

- Figma deck embed — visitor can flip through the presentation inline

### Reflections *(optional)*

- Learnings, what you'd do differently
